# Color Database

原生 HTML、CSS、JavaScript 配色浏览工具。内置完整 229 组方案，包含 2–51 色，无第三方依赖、构建步骤或后端。

在线访问：[Color Database](https://xiasheng32.github.io/colorDatabase/page/) · 公开仓库：[xiasheng32/colorDatabase](https://github.com/xiasheng32/colorDatabase)

## 文件结构

```text
colorDatabase/
├── README.md          # 使用说明
└── page/
    ├── index.html     # 页面结构与内置图标符号
    ├── style.css      # 布局、主题、系统字体与切换动画
    ├── script.js      # 配色数据、筛选、收藏、复制与 SVG 图表
    └── icon.svg       # 透明背景的木质拟物网站图标
```

## 打开页面

直接双击 `page/index.html` 即可离线使用，保留同目录下的另外三个文件。

也可以在 `colorDatabase/` 目录运行以下命令，通过本地 HTTP 访问；此方式需要 Python 3：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory page
```

随后打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。

## 部署与更新

GitHub Pages 使用 **Deploy from a branch**，发布源为 `main` 分支的 `/ (root)`。推送后由 GitHub 自动构建并发布，页面入口位于 `page/`，无需添加仓库工作流文件。

修改完成后，在 `colorDatabase/` 目录提交并推送：

```sh
git add page README.md
git commit -m "Update Color Database"
git push origin main
```

## 使用方式

- 搜索编号、名称、来源或 HEX 色值，并按来源、颜色数量联合筛选；点击爱心收藏，通过“收藏”查看已保存的方案。来源选项为知乎（177）、ggsci（28）、grDevices（16）、RColorBrewer（8），括号数字表示该来源的全部方案数。
- 列表最多显示前 10 个小色块，额外颜色通过“+数量”提示。点击方案打开预览，四张 SVG 图表采用 2×2 布局，每张画布比例为 4:3；固定示例数据只更换颜色，便于比较。超过 16 色的方案仅使用前 16 色绘图，并明确提示。
- 四图依次为柱状图、重叠密度图、散点图和折线图。密度图使用固定样本的高斯核密度估计，以半透明填充和同色曲线展示各组分布的重叠效果；坐标范围按展示组数收紧，减少曲线周围的留白，相同色数使用相同样本与坐标范围。
- 完整色值每页 10 色，可通过箭头翻页；切换或重新打开方案回到第一页。点击小色块复制单色，“复制全部”复制整组，包含所有分页中的颜色。自动复制受限时，会提供可选择的文本供手动复制。
- 不透明度滑条同步控制四图的数据图形，范围 0–100%，默认 100%；坐标轴和色值小方块保持清晰。拖动实时更新，按压滑块放大、释放回弹。不透明度在切换方案和重新打开预览时保留，刷新页面恢复默认。
- 预览根据窗口高度自动调整图表尺寸；较矮的窗口将滑条和色值放到图表右侧，保留四图一屏查看。
- 顶部胶囊控件切换中文／英文、浅色／深色；图表标题保留英文。界面统一使用系统默认字体，切换带过渡动画，并适配系统减少动态效果设置。
- 收藏、语言和外观选择保存在浏览器的 `localStorage` 中。未指定外观时跟随系统主题；浏览器禁止存储时仍可在当前页面使用。

存储按浏览器和访问来源区分。直接打开文件与通过 HTTP 访问可能使用独立的设置和收藏，不会自动同步。

## 数据说明

229 组方案保留原始编号 1–229、来源、名称、颜色顺序和重复记录。第 123 组的 `#T3ABCF` 是无效色值，页面会明确提示并使用灰色占位；复制时保留原文。

搜索、来源和色数筛选仅在当前页面内生效，刷新恢复全部方案。透明度只影响绘图显示，复制始终使用原始 HEX。
