# ColorSet

**中文：** ColorSet 是一个包含 215 组配色的浏览器工具，支持搜索、筛选、收藏、复制色值和图表预览。无需安装或构建，也可离线使用。

**English:** ColorSet is a browser-based palette tool with 215 schemes, search, filters, favorites, color copying, and chart previews. No installation or build is required, and it works offline.

## 目录

```text
ColorSet/
├── README.md
└── page/
    ├── index.html   页面入口
    ├── style.css    页面样式
    └── script.js    配色数据与浏览器交互
```

## 使用

在线使用：[打开 ColorSet](https://xiasheng32.github.io/ColorSet/page/)，无需下载。

双击 `page/index.html`，或在浏览器中打开该文件，即可离线使用。CSS 和 JavaScript 通过相对路径加载，请保持这些文件位于同一目录。标签页图标使用内嵌的 🛼 emoji，无需独立图标文件。

也可将 `page` 目录中的文件放到任意静态网站托管服务中。搜索、筛选、预览和复制均在浏览器本地完成，配色数据随页面加载，离线使用无需联网。

现有 GitHub Pages 发布源为 `main` 分支的 `/ (root)`，页面入口位于 `page/`；提交并推送到 `main` 后自动更新，无需添加仓库工作流文件。

## 功能

- 内置 215 组、2–16 色方案，来源为知乎（177）、ggsci（25）和 grDevices（13）；编号 1–215 连续，保留名称、来源与颜色顺序，已去除颜色序列完全重复的组合和超过 16 色的组合。
- 搜索编号、名称、来源或 HEX 色值，支持来源、颜色数量和收藏联合筛选。点击爱心收藏，通过“收藏”查看已保存的方案。
- 列表最多显示前 10 个小色块，额外颜色通过“+数量”提示。点击方案打开预览，四图依次为柱状图、箱形图、散点图和折线图；使用固定示例数据，只更换颜色，便于比较。
- 四图采用 2×2 布局，每张画布比例为 4:3；柱状图与箱形图保留轮廓线，图表标题使用英文。
- 完整色值每页 10 色，切换或重新打开方案回到第一页；多页方案的翻页控件位于色块行右侧。点击小色块复制单色，“复制全部”复制整组，包含所有分页中的颜色；自动复制受限时提供可选择的文本供手动复制。
- 不透明度滑条同步控制四图的数据图形，范围 0–100%，默认 100%，每 20% 显示一个刻度点。滑条上方不设文字标签，百分数作为读数跟随滑块手柄左右移动并实时更新；拖动时图形同步变化，滑块经过刻度点时放大回弹；坐标轴和色值小方块保持清晰，复制始终使用原始 HEX。
- 顶部胶囊控件切换全部／收藏、中文／英文和深浅主题；未指定外观时跟随系统主题。收藏、语言和外观选择保存在浏览器的 `localStorage` 中。
- 黑白灰界面搭配小方块色值，适配窄屏；预览根据窗口高度调整图表尺寸，较矮的窗口将滑条和色值放到右侧，保留四图一屏查看。系统“减少动态效果”时关闭动画。
- 统一使用系统默认字体（`system-ui, sans-serif`），不读取本机字体目录，不下载字体文件。

搜索、来源、色数和收藏筛选仅在当前页面内生效，刷新恢复全部方案；不透明度在切换方案时保留，刷新恢复 100%。设置和收藏按浏览器及访问来源分别保存，直接打开文件与通过 HTTP 访问不会自动同步；浏览器禁止存储时仍可在当前页面使用。

第 123 组的 `#T3ABCF` 是原始数据中的无效色值，页面会明确提示并使用灰色占位，复制时保留原文。
